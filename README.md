## ต้องเตรียมอะไรบ้าง

# มันแก้ปัญหาอะไร

ให้ AI ถอดเสียงเป็น `.srt` แล้วเอาเข้า CapCut มักเจอว่าซับกับเสียงเหลื่อมกัน
และยิ่งเหลื่อมหนักเมื่อย่อคำให้สั้นลงเพื่อเน้นคำสำคัญ

สาเหตุคือ timestamp ที่ได้มาเป็นการ**ประมาณจากบริบท** ไม่ได้จับคู่กับเสียงจริง
เครื่องมือนี้แยก **ข้อความ** ออกจาก **เวลา** แล้วให้แต่ละอย่างมาจากเครื่องมือที่ถนัดที่สุด

```
ไฟล์เสียง
   ├─→ Gemini ────────→ ข้อความ (แม่นเรื่องคำไทย ศัพท์เฉพาะ ชื่อคน)
   └─→ Whisper align ─→ เวลาของทุกตัวอักษร (จับคู่กับเสียงจริง)
                            ↓
                       words.json
                            ↓
                    ย่อคำได้ตามใจ
                            ↓
          ค้นคำที่เหลือกลับใน words.json แล้วหยิบเวลาของคำนั้นมาใช้
                            ↓
                        .srt ที่ตรงคำ
```

ตัวอย่างจากคลิปทดสอบ — ย่อ "วันนี้เราจะมาคุยกันเรื่องการนอนหลับให้มีคุณภาพ"
เหลือ "การนอนหลับให้มีคุณภาพ"

| | เวลาที่ซับขึ้น | ผล |
|---|---|---|
| ใช้เวลาของก้อนเดิม | 1.24 | ขึ้นเร็วไป 2 วินาที |
| **subtitle-align** | **3.24** | ตรงกับที่คำว่า "การนอน" ดังจริง (3.30) |

# ย่อคำให้สั้นกว่าที่พูด

ซับที่ได้มาจะตรงกับที่พูดทุกคำ ถ้าอยากย่อให้เหลือเฉพาะคำสำคัญ มีสองทาง
เลือกตามปริมาณงาน

## แก้ไม่กี่ก้อน — ทำใน CapCut เลย

เร็วกว่า เพราะเห็นภาพกับเสียงพร้อมกัน

แต่ต้องรู้ว่า **ลบคำในกล่องข้อความแล้วเวลาไม่ขยับตาม** — ต้องลากขอบซับให้ตรง
คำที่เหลือด้วย ไม่งั้นซับจะขึ้นเร็วไปตามเวลาเดิมของก้อน ซึ่งคือปัญหาที่เครื่องมือนี้
แก้มาแต่แรก

## ย่อทั้งคลิป — แก้ในไฟล์ แล้วให้คำนวณเวลาใหม่ให้

บอก Claude ว่า "ขอย่อคำเอง" มันจะบอก path ของไฟล์ `edit.txt` มาให้ หน้าตาแบบนี้

```
[2] 00:00:01.240 → 00:00:05.560
วันนี้เราจะมาคุยกันเรื่องการนอนหลับให้มีคุณภาพ
```

แก้เฉพาะ**บรรทัดข้อความ** บรรทัดเวลาเป็นแค่ข้อมูลอ้างอิง ห้ามลบ

| อยากทำ | ทำยังไง |
|---|---|
| ย่อคำ | ลบคำที่ไม่เอาออกจากบรรทัดข้อความ |
| ตัดก้อนนั้นทิ้ง | ลบข้อความจนเหลือบรรทัดว่าง |
| แยกเป็นสองซับ | ใส่ `\|` คั่นกลาง |

**ห้ามพิมพ์คำใหม่ที่ไม่มีในเสียง** — จับเวลาไม่ได้ ระบบจะเตือนแล้วถอยไปใช้เวลาของ
ก้อนเดิมแทน (ยังใช้ได้ แค่ไม่แม่นเท่า)

เสร็จแล้ว save แล้วบอก Claude ว่าแก้เสร็จแล้ว

# ตัดคลิปสั้นจากคลิปยาว

**กฎเหล็ก: ทำซับหลังตัดคลิปเสร็จเสมอ** ถ้าตัดต่อเพิ่มหลังทำซับ เวลาจะเลื่อนทั้งหมด

**ตัดหัวท้ายอย่างเดียว** — ไม่ต้อง export ก่อน บอก Claude ว่าเอาเฉพาะช่วงไหน
หรือสั่งเองว่า

```bash
python3 align.py full.mp4 --from 12:30 --to 13:05 --max-chars 24
```

เวลาใน SRT จะนับ 0 ที่ 12:30 ตรงกับคลิปที่ตัดออกมาพอดี
รูปแบบเวลาที่รับ: `90` (วินาที), `1:30`, `12:30.5`, `1:02:30`

**มี jump cut ข้างใน** — ตัดใน CapCut ให้จบ export ออกมาก่อน แล้วค่อยทำซับจากไฟล์นั้น

**คลิปยาวเกิน ~10 นาที** — เครื่องมือนี้ไม่ได้ทำมาสำหรับไฟล์ยาว ให้หาช่วงที่จะใช้ก่อน
แล้ว align เฉพาะช่วงนั้น

# เลือกโมเดลถอดข้อความ

```bash
python3 align.py clip.mp4 --gemini-model pro
```

ผลทดสอบกับคลิปโฆษณาภาษาไทย 67 วินาที:

| โมเดล | ผลที่ได้ |
|---|---|
| `flash` (ค่าเริ่มต้น) | อยู่ใน free tier แน่นอน แม่นพอใช้งานจริง แต่มักเขียนชื่อแบรนด์เป็นภาษาอังกฤษ ("Health at Home" แทน "เฮลท์แอทโฮม") ซึ่งงานมาร์เก็ตติ้งมักอยากได้แบบนั้นอยู่แล้ว |
| `pro` | เขียนไทยล้วนตามเสียงพูด แม่นกว่านิดหน่อย แต่โควต้า free tier น้อยกว่ามาก |
| `flash-lite` | ไม่แนะนำ — ไม่เว้นวรรคระหว่างวลี และเขียนตัวเลขเป็นเลขอารบิก ทำให้แบ่งก้อนซับพลาด |

เทียบเวลาที่ align ได้ระหว่าง `flash` กับ `pro` ต่างกันเฉลี่ย **0.024 วินาที**
มากสุด 0.073 — น้อยกว่า 2 เฟรมที่ 30fps คือมองไม่ออกด้วยตา

โมเดลมีผลกับ **ข้อความ** อย่างเดียว ส่วน **เวลา** มาจาก Whisper บนเครื่องเสมอ

> เปลี่ยนโมเดลแล้วอยากถอดใหม่ ต้องลบ `work/<ชื่อ>/transcript.txt` ก่อน
> ไม่งั้นมันจะใช้ข้อความเดิมที่มีอยู่

## ข้อควรรู้เรื่องข้อมูล

Google ระบุว่าเนื้อหาที่ส่งผ่าน **free tier ถูกนำไปใช้ปรับปรุงผลิตภัณฑ์**
ส่วน **paid tier ไม่ถูกนำไปใช้**

คลิปโฆษณาที่จะเผยแพร่อยู่แล้วไม่มีปัญหา แต่ถ้าเป็นคลิปที่มีข้อมูลส่วนบุคคล
ข้อมูลสุขภาพ หรือบทสัมภาษณ์ที่ยังไม่เผยแพร่ ให้ใช้ key ที่เปิด billing แล้ว

## ถ้าไม่อยากส่งขึ้น cloud เลย

Whisper ที่ลงไว้ถอดเสียงเองได้ แต่ทดสอบกับคลิปไทยเดียวกันแล้วใช้ไม่ได้จริง —
ชื่อบริษัทกลายเป็น "Hell at Home", "อบรมฟรี" กลายเป็น "อบลมฟี" และไม่เว้นวรรคเลย
จึงยังต้องพึ่ง Gemini สำหรับข้อความ

# ตัวเลือกทั้งหมด

## align.py

| flag | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| `--gemini-model` | `flash` | โมเดลถอดข้อความ: `flash` / `pro` / `flash-lite` |
| `--from` | — | ตัดเฉพาะช่วง เริ่มที่ (เวลาใน SRT นับ 0 ที่จุดนี้) |
| `--to` | — | ตัดเฉพาะช่วง จบที่ |
| `--max-chars` | `42` | ตัวอักษรสูงสุดต่อซับหนึ่งก้อน (คลิปแนวตั้งใช้ `24`) |
| `--max-gap` | `0.4` | ช่วงเงียบกี่วินาทีถึงตัดก้อนใหม่ |
| `--no-srt` | — | หยุดที่ `edit.txt` ไม่ต้องสร้าง SRT (ใช้เมื่อจะย่อคำก่อน) |
| `--model` | `medium` | ขนาด Whisper ที่ใช้จับเวลา: `small` / `medium` / `large-v3` |
| `--device` | `cpu` | `cpu` / `mps` / `cuda` |
| `--name` | ชื่อไฟล์ | ชื่อโฟลเดอร์งาน |
| `--work` | `./work` | โฟลเดอร์เก็บงาน |

## make_srt.py

ใช้เมื่อแก้ `edit.txt` แล้วอยากสร้าง SRT ใหม่ หรืออยากปรับจังหวะซับ
โดยไม่ต้อง align ใหม่

| flag | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| `--min-dur` | `0.7` | ความยาวขั้นต่ำต่อซับ กันซับกระพริบ |
| `--lead` | `0.06` | เผื่อเวลาก่อนคำแรก ให้ซับขึ้นก่อนเสียงนิดหนึ่ง |
| `--tail` | `0.18` | เผื่อเวลาหลังคำสุดท้าย |
| `--gap` | `0.04` | ช่องว่างขั้นต่ำระหว่างซับสองก้อน |
| `--window-pad` | `0.6` | ขยายกรอบค้นหาของแต่ละก้อน |
| `-o` | `work/<ชื่อ>/<ชื่อ>.srt` | path ไฟล์ผลลัพธ์ |

## ไฟล์ที่ได้ใน work/&lt;ชื่องาน&gt;/

| ไฟล์ | คืออะไร | แก้ได้ไหม |
|---|---|---|
| `audio.flac` | เสียงที่ดึงออกจากวิดีโอ | ลบได้ ถ้าอยากเริ่มใหม่ |
| `transcript.txt` | ข้อความดิบจาก Gemini | **แก้ได้** ถ้าถอดผิดคำ แล้วรัน `align.py` ซ้ำ |
| `words.json` | เวลาของทุก token ที่จับคู่กับเสียงจริง | **ห้ามแก้** |
| `edit.txt` | ไฟล์กลางสำหรับย่อคำ | **แก้ตรงนี้** |
| `<ชื่องาน>.srt` | ผลลัพธ์ | ลากเข้า CapCut ได้เลย |

# แก้ปัญหา

บอก Claude ตรง ๆ ได้เลยว่าเจออะไร มันแก้ให้ได้เกือบทั้งหมด ส่วนนี้ไว้อ้างอิง

**ถอดผิดคำ หรือตกคำ**
แก้ `work/<ชื่อ>/transcript.txt` แล้วรัน `align.py` ซ้ำ — มันจะข้ามขั้นเรียก Gemini
เพราะไฟล์มีอยู่แล้ว แล้ว align ใหม่จากข้อความที่แก้

**ซับก้อนยาวเกินไป**
ลด `--max-chars` แต่ระบบตัดได้เฉพาะตรงรอยเว้นวรรค ถ้าคลิปพูดรัวไม่มีจังหวะหยุด
ก้อนจะยาวกว่าที่ตั้งไว้ — เป็นข้อจำกัดของภาษาไทยที่ไม่มีช่องว่างระหว่างคำ

**ซับขึ้นเร็วหรือช้าไปทั้งไฟล์**
ปรับ `--lead` / `--tail` ตอน `make_srt.py` ไม่ต้อง align ใหม่

**"จับคู่กับเสียงไม่ได้ชัด" ตอนสร้าง SRT**
ก้อนนั้นมีคำที่ไม่มีในเสียง แก้ให้ใช้คำเดิมแล้วรันซ้ำ

**`CERTIFICATE_VERIFY_FAILED` ตอนโหลด Whisper model**
`align.py` ตั้ง `SSL_CERT_FILE` จาก certifi ให้แล้ว ถ้ายังเจอ เช็คว่า `pip3 install certifi` แล้ว

**อยากเริ่มใหม่ทั้งหมด**
ลบโฟลเดอร์ `work/<ชื่อ>/` แล้วรันใหม่

# ข้อจำกัด

- ทดสอบกับเสียงพูดไทยที่ค่อนข้างชัด ยังไม่ได้ทดสอบกับเสียงเพลงคลอดัง
  หรือคนพูดทับกันสองคน
- `--from` / `--to` ใช้ได้เฉพาะกรณีตัดหัวท้าย
- ไม่มีการแบ่ง chunk — คลิปยาวเกิน ~10 นาทีจะช้าและอาจติด limit ของ Gemini
- Whisper ตัด token ภาษาไทยเป็นตัวอักษรเดี่ยว การแบ่งก้อนจึงอาศัยการเว้นวรรค
  ที่ Gemini ใส่ตามจังหวะพูด ไม่ใช่การตัดคำแบบ dictionary

# ติดตั้งเองแบบไม่ผ่าน Claude

```bash
git clone https://github.com/sundayfifth/subtitle-align.git ~/.claude/skills/subtitle-align
cd ~/.claude/skills/subtitle-align
pip3 install -r requirements.txt
cp .env.example .env      # แล้วใส่ GEMINI_API_KEY ในไฟล์
```

ต้องมี `ffmpeg` ด้วย (`brew install ffmpeg`) และ Python 3.10 ขึ้นไป

เช็คว่าครบ:

```bash
python3 -c "import stable_whisper, google.genai, certifi; print('ok')" && which ffmpeg
```

key หาจาก 3 ที่ตามลำดับ: environment variable `GEMINI_API_KEY` →
`.env` ในโฟลเดอร์ที่รันอยู่ หรือข้าง ๆ `align.py` → `~/.config/subtitle-align/.env`

# ข้างในทำงานยังไง

`align.py`
1. `ffmpeg` ดึงเสียงเป็น FLAC 16kHz mono (ตัดช่วงตาม `--from`/`--to` ถ้ามี)
2. ส่งให้ Gemini ถอดเป็นข้อความล้วน — prompt สั่งไม่ให้ใส่ timestamp
   ให้เว้นวรรคตรงจังหวะที่คนหยุดพูดจริง และเขียนตัวเลขเป็นตัวหนังสือตามที่ได้ยิน
3. `stable-ts` เอาข้อความไป forced-align กับเสียง ได้เวลาของทุก token
4. จับ token เป็น "วลี" ตามรอยเว้นวรรค แล้วแพ็ควลีเป็นก้อนซับตาม `--max-chars`
